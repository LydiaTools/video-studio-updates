# Video Studio

A public development journal for a local macOS video production tool: research and original narration, scene planning, approved audio, reference discovery, and a shared material library.

**Current local build: 0.3.1 build26 (2026-10-09).** The latest update replaces the dynamic information-card route with a Remotion vertical composition and keeps the Hypit production handoff. The 16-second silent visual sample was reviewed; a complete source-backed, voiced episode still needs acceptance.

This repository publishes changes and verification boundaries for each internal build. The source and historical app archives are kept in a private repository. A general installer for other computers has not been validated.
